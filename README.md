# Scholar Thubalami Nkomazana — Portfolio

Personal portfolio of **Scholar Thubalami Nkomazana** — AI Engineer, Founder & CEO of Axterion.

> *Proximity is the locus of accretion and emergence.*

## Stack
Zero-build static site — plain HTML, CSS and vanilla JavaScript. No dependencies.

- `index.html` — all content
- `css/styles.css` — design system (Bodoni Moda · Schibsted Grotesk · Martian Mono; obsidian / ivory / ember)
- `js/main.js` — interactions: accretion particle field, role scramble, scroll-scrubbed text, stacking project cards, live data visuals, neural constellation, magnetic cursor, ⌘K command palette
- `assets/` — STN logo (`logo.svg`) and portraits

## Run locally
```bash
npx http-server .   # or: python3 -m http.server
```

## Deploy (GitHub Pages)
Settings → Pages → **Deploy from a branch** → pick the branch and `/ (root)` → Save.
